# Tata-Motors-V.T
Rear Axle Division – Power BI Inventory Dashboard Project
Designed an interactive Power BI dashboard to analyze 110+ Cr of aging inventory across 6,000+ rear axle parts.– Leveraged DAX, Excel, and visual filters to classify inventory using QMSG levers and dynamically track buyer
level scrap value.– Enabled stakeholder-driven insights through slicers and KPI cards by category, plant, and inventory age bands.– Improved reporting turnaround by 70% through automated visuals and real-time part-level tracking
